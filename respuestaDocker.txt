// Responde a la pregunta sobre docker del enunciado

| ----------------------------------------------- |
| docker run -d --name mi_web -p 8080:80 nginx    |
| ----------------------------------------------- |

docker run -d  
Ejecuta un contenedor en modo detached, lo que significa que se inicia en segundo plano y no bloquea la terminal.

--name mi_web  
Asigna un nombre personalizado al contenedor. En este caso, el contenedor se llamara mi_web.

-p 8080:80  
Realiza un mapeo de puertos:

8080 es el puerto de nuestro ordenador.

80 es el puerto interno del contenedor donde se ejecuta Nginx.

nginx  
Indica que el contenedor debe crearse a partir de la imagen oficial de Nginx, un servidor web ligero y de alto rendimiento.
